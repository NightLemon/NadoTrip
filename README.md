# NadoTrip

NadoTrip is a static MVP for a bilingual France travel sales application. It is designed for GitHub Pages and works without a build step.

## MVP scope

- English and French language toggle
- Responsive mobile, tablet, and desktop layout
- France travel product marketplace with filters
- Suggested route section for sales packaging
- Booking-intent form that stores the latest request in local storage

## Local preview

Open `index.html` directly or run a local static server from this folder.

```powershell
python -m http.server 8080
```

## GitHub Pages

This repo can be published from the `main` branch root folder.
